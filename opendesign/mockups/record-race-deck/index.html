Method · scripting

Three conventions that keep the numbers honest

  • Units: def files store SI, script set expects practical units — SI inputs inject a 106× overdose
  • Cross-sections: the σ set-key restructures the block instead of scaling it — definition files only
  • Uncertainty: 0.017-point IV-step; every reported difference is read against it

Honesty · scripting

Two scripting traps that fabricate cells

  • Units trap: SI-valued set inputs overdose 106× — ghost cells up to 27%
  • σ trap: the capture cross-section set-key neutralises interfaces instead of scaling them
  • Rule: definition files for structure, set-then-get verification always
Guardrails for the Record Race17 / 20
SPEAKER NOTES 17: We publish our mistakes as findings. Both traps produced plausible-looking efficiencies — that is what makes them dangerous. The verification rule is one line: read back every scripted value before believing the run.

Contribution · standard

A checklist for comparable SCAPS claims

  • Interface status + Nif + σ (or S) · bulk Nt + σ (or τ)
  • Unit-system declaration · Rs basis, computed not assumed
  • Both contact work functions · surveyed vs adopted affinities
  • Model-derived radiative screen · archived receipts

Limits

What this work cannot say

  • No optimiser brackets the champion — best-of-evaluated, not proven optimal
  • No phase stability, ion migration, or damp-heat — SCAPS steady state only
  • No experimental calibration — the loss budget compares, it does not fit
